# Product

## Register
product

## Users
One Windows PC owner switching between couch gaming, streaming, browsing, and normal desktop work. Both PlayStation and Xbox controllers, keyboard and mouse are supported.

## Product Purpose
Turn Windows sign-in into a useful console experience with real installed games and services. Success means launching content with a controller and returning to an unchanged, usable Windows desktop at any time.

## Brand Personality
Calm, cinematic, familiar. Classic PS5 Games/Media interface is the explicit visual reference approved by the user.

## Anti-references
Generic dashboards, neon gaming panels, fake PSN features, decorative statistics, browser landing pages, forced shell replacement.

## Design Principles
Content takes the foreground. Every tile launches something real. Controller focus is always clear. Desktop access is immediate. Preserve the user's browser and accounts.

## Accessibility & Inclusion
Readable TV typography, visible focus, controller/keyboard equivalence, reduced motion, adjustable interface sounds. Error messages describe a recovery action.
